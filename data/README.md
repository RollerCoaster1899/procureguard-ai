# ProcureGuard AI Synthetic Dataset

## Source

The dataset is generated deterministically by code in
`src/procureguard/data/generator.py`. There is no external source and no
download step. Everything is synthetic and fictional.

## Contents

| Artifact | Description |
|---|---|
| `corpus.json` | 45 documents (24 supplier profiles, 10 policy documents, 11 category guides) |
| `scenarios.json` | 24 procurement scenarios (12 train / 6 validation / 6 test) |
| `queries.json` | 24 retrieval queries with qrels |
| `qrels.json` | Binary relevance judgements per query |
| `fixture_facts.json` | Supplier-level risk, budget, compliance, and spend facts |
| `seed.json` | Random seed used for generation (42) |
| `validation_report.json` | Result of deterministic data validation |

## License and Provenance

The data is released under the same MIT license as the repository. It contains
no real company names, personal data, or PII. Supplier names such as "Vertex
Manufacturing Ltd" are fictional and any resemblance to real entities is
coincidental.

## Known Biases and Limits

- The corpus is small (45 documents) and synthetic; retrieval findings may not
  transfer to real enterprise corpora.
- Supplier profiles are hand-curated to cover a balanced mix of approve, review,
  and reject outcomes, which is not representative of a real supplier base.
- Scenarios within a split reuse supplier-level facts, so outcomes are
  structured rather than fully independent.

## Regeneration

```bash
uv run python scripts/reproduce.py          # full dataset and artifacts
uv run python scripts/reproduce.py --smoke  # small subset
```

The dataset is regenerated by these commands; nothing in `data/processed` is
hand-written.
