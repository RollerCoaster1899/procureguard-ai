# Contributing to ProcureGuard AI

Contributions are welcome. This project follows the repository conventions in
the workspace `AGENTS.md`.

## Development Setup

```bash
uv sync --extra dev
```

## Conventions

- Python >= 3.11, `src/procureguard` layout, lowercase module names.
- Use camelCase for functions, methods, and variables, except for framework
  names and external schemas.
- All public boundaries are typed; mypy runs in strict mode on `src/`.
- Code must be deterministic: no unseeded randomness in production paths.

## Quality Gates

```bash
make lint
make format-check
make typecheck
make test
make smoke
make security
```

All gates must pass before a pull request is reviewed.

## Tests

- Unit tests: `tests/unit/`
- Integration tests (MCP stdio roundtrip, workflow engine, API): `tests/integration/`
- End-to-end smoke tests: `tests/smoke/`

The default test suite never calls external APIs and needs no network or API key.

## Adding a Result

Every reported number must be generated by code. Run the full offline
experiment, then refresh the README:

```bash
uv run python scripts/reproduce.py
uv run python scripts/update_readme.py
```

Never hand-edit metrics in the README or reports.
